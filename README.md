# Сайт Олеси Павлюковой

Главная, «Психология и коучинг», «Метод резонансной релаксации» и страницы-заглушки
«Архетипы и символы», «Авторские ретриты» (их макеты ещё не готовы).

## Структура
- `public/index.html` — главная (`css/home.css`, `js/home.js`)
- `public/psychology.html` — психология и коучинг (`css/base.css`, `css/psychology*.css`, `css/print.css`, `js/psychology.js`)
- `public/resonance.html` — метод резонансной релаксации (`css/resonance.css`, `js/resonance.js`)
- `public/archetypes.html`, `public/retreats.html` — заглушки в оформлении главной
- `public/assets/` — все фотографии и дипломы
- `server.js` — сервер для Railway (Express, отдаёт папку `public`)

## Запуск
```
npm install
npm start          # http://localhost:3000
```

## Railway
Новый проект → Deploy from GitHub repo (или загрузка папки через Railway CLI: `railway up`).
Railway сам выполнит `npm install` и `npm start`; порт берётся из переменной `PORT`.
Settings → Networking → Generate Domain — получить адрес; там же можно подключить свой домен.
Healthcheck Path: `/health`.

## Оракул 64 ключей (страница «Архетипы и символы», блок #oracle)
По ТЗ «Олеся Оракул 64 ключа». Встроен в `archetypes.html`, отдельного адреса нет; шаги переключаются внутри блока.
- `js/oracle-core.js` — логика: три монеты (сторона А = 2, Б = 3, `crypto.getRandomValues`), линии снизу вверх,
  номер по таблице Вэнь-вана (сверена со справочной таблицей, все 64 клетки).
- `js/oracle.js` + `css/oracle.css` — интерфейс: знакомство → вопрос → 6 бросков → гексаграмма → карта → размышления.
- `js/oracle-keys.js` — **данные колоды, заполняет автор**: название ключа, путь к карте, тема, Тень/Дар/Сиддхи, вопросы.
  Пока у ключа нет карты и текстов, показывается демонстрационная карта с пометкой.
- `assets/oracle/cards/` — сюда кладутся карты `key-01.jpg … key-64.jpg` (JPG 1024×1536).
- `oracle-integration/oracle-block.html` — разметка блока отдельно, для переноса в настоящую страницу «Архетипы и символы».
- Тесты логики: `node tests/oracle-core.test.js` (все 64 сочетания, проверочные случаи, направление снизу вверх, равномерность).
- Вопрос пользователя никуда не отправляется и не сохраняется. «Исследовать ключ глубже» ведёт к `#offers`, а пока такого раздела нет — к контактам.
